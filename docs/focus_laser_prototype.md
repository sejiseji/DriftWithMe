# 一点集中砲火レーザーのローカル試作

`?debug=weeks` / Macの `--week-debug` → Nudibranch sprite test → Laser test。
レーザー画面は遮蔽物の少ない草地から開始（水辺へ切替可）。
Fire / Replayで始動。NORMAL/ABNORMALで対象を切替。Cancelで技だけ取消。
Pause、地形切替、週メニュー、通常タイトルへの復帰も利用できる。
通常の敵・戦闘・案件やセーブへ登録する技ではない。

泡捕縛済みの対象を想定した表示試作。ヒューズの既存牽制描画の序盤だけを使い、
ジャックの位置から6個の泡を対象上空の緩い半円へ送る。ヒューズから各泡へ
弓形の光が時間差で飛び、到達した泡で短い着光を挟んで、加速する直線へ切り替わる。
先着した泡から対象の同じ一点へ照射。着弾後は触手込みの合成フレームをドット単位で
焼失させる。全画面点滅や敵のAI・電撃・報酬・7月案件の変更は行わない。

幾何・33点の曲線は始動時、投影はカメラ変更時のみ計算。
焼失画像は始動フレームに対し25段階で一度だけ用意し、毎フレームの画像生成を避ける。
火花は最大8点。技はEffectSystemの永続プールへ追加しないため、取消・終了で残留しない。
再実行は新しい技状態で上書き。方向・対象・地形変更は進行中の技を破棄。
通常セーブとバックアップは週移動テストの一時ストア・二重の保存拒否で保護する。

実戦への境界: FocusLaserActionは演出のみを受け持つ。今後、泡捕縛成功後に
技状態を開始し、着弾/完了のタイミングを戦闘側の確定結果へ接続する必要がある。
この試作はダメージ・資源消費・撃破判定・ドロップを変更せず、戦闘完成とは扱わない。
公開版でも週移動デバッグの表示試験に限定し、通常進行へ組み込まない。

水辺のレーザー試作は柱の遮蔽を避けるため、スプライト試験中心から48だけ東へ
舞台中心をずらす。対象・ジャック・ヒューズとカメラのみの一時配置で、地形や通常の敵配置は変えない。

攻撃中のジャック／ヒューズは既存front_right（画面SE）スプライトを選ぶ。
座標・移動方向・通常の向きキャッシュには書き込まず、終了・取消・退出で通常選択へ戻す。
泡の始点をジャックの前側へ、レーザーの始点をヒューズの右前面へ寄せる。
6ビットの配置と各段階の開始・終了時間は変更しない。
