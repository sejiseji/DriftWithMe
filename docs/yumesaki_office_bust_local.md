# Yumesaki approved counter busts (local)

The five approved flat 116×116 portraits are registered as
`yumesaki_bust_normal`, `yumesaki_bust_smile`, `yumesaki_bust_worried`,
`yumesaki_bust_surprised`, and `yumesaki_bust_thinking`.
They are byte-identical HEX copies from the approved flat-expression package
Library `libfile_2410d05ef5e48191a91e524c035f2d46`, version 0.
The earlier noisy busts are not adopted.

Only the July W2 researcher counter visitor uses these busts. Existing map
knees and map actors retain their original files and drawing methods. Current
counter pages select the visible speaker: Miyano restores her existing portrait
and name, Jack's page restores the neutral Yumesaki visitor portrait. The active
authored Yumesaki turn determines emotion before wrapping: her opening uses
neutral, the existing unresolved-cause line uses worried. The other three
approved expressions are registered but no dialogue was added to force them.

Emotion is derived on every draw and adds no save fields. Existing dialogue
snapshots restore the authored turn and derive the same portrait. There is no
expression state to carry into a later speaker, case, or week. Visitor fitting
uses the existing centered, uniform scale and colkey 8, with the audited default
palette. Existing map/full-body assets are untouched.

This is local integration only; no commit, push or publication.
