# 月・週を選ぶテスト用メニュー

Web版はURLに `?debug=weeks` を付けて起動する。既存のクエリがある場合は
`&debug=weeks` を追加する。Mac版は `python main.py --week-debug` で起動する。
通常起動ではメニューは表示されない。

6月第1〜4週を選び「選んだ週の最初から始める」をタップする。
7・8月は準備中のため開始できない。プレイ中の「週選択・保存なし」で選び直せる。
「取消・テストに戻る」は現在のテストを続け、「通常プレイへ戻る」はタイトルへ戻る。

テスト中の進行は一時セッションだけで扱い、通常セーブとバックアップは読み書きしない。
再読込するとテストの進行は消え、週選択からやり直す。通常復帰時に通常保存を読み直す。
週の開始時は会話・戦闘・外勤・遷移などを初期化し、対象週に必要な前提だけを設定する。

対象週のUI・案件の検証では、このメニューで前工程をスキップしてよい。
週遷移や前提条件の回帰検証は通常の順番で進める経路も残す。
検証結果には「デバッグ経由」または「通常経路」を記載し、両者を区別する。
保存安全性は個人の保存を使わず、専用ブラウザプロファイルと合成セーブで検証する。
