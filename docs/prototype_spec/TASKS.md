# 実装ウェーブ / Jack World P0

各ウェーブの目的は、次の作業が安全に積み上がる「動く状態」を残すこと。日数・時間の見積もりは置かない。コミット／pushはユーザーと既存リポジトリの方針に従う。

## 最初に実行する範囲

**JWP000 → JWP001 → JWP002 のみ。** 広い正方形マップをPCとモバイル向けに動かすE0を作り、そこで報告する。JWP003以降は仕様として保持し、最初の指示だけで全量実装しない。

## JWP000 — 現行環境の確認

### 作業

現在の作業フォルダ内のAGENTS/README/pyproject/依存定義とgit statusを読む。既存Riversideが実在する場合は、投影・カメラ・入力排他・AABB・テキスト・音声の実装を読む。会話に出た過去のcommitやローカル絶対パスだけを信用しない。

使用Python/Pyxel版とWebランタイムを記録する。既存版のまま必要機能が満たせるなら、不必要な全体アップグレードをしない。ネイティブとWebの版がずれている場合は、差を記録して互換な組合せへ固定する。

同梱の `python3 tools/validate_spec_data.py` を実行する。このコマンドは仕様パックのルートで使うもの。実装先へ取り込んだ後はパスをREADMEへ記録する。

### 成果

`docs/prototype_environment_audit.md` 相当の短い監査メモ。再利用する部分、独立実装する部分、実行・テスト・Webビルドのコマンド、確認していない環境を示す。環境調査だけで最初のウェーブを終えず、実装可能なJWP001へ続ける。

## JWP001 — 地面・移動・衝突

### 最低限の実装

付属JSONを読む。平坦1024四方の地面、16立方体、少数の障害物、共有投影、基準カメラ、矢印/WASD、停止、斜め正規化、外周とAABB滑り、実移動量、デバッグ表示を作る。

最初は全64チャンクの粗判定と候補物体の投影でよい。描画だけの最適化を先に複雑化しない。ただし地面・衝突のデータは同じ正本から読む。

### ゲート

ACCEPTANCEのDATA群、MOV群、REN01/02/04/05、TIME01の該当部分。ビューが追従していてキャラクターが中央に留まる場合でも、固定カメラ試験で入力方向の正しさを確認する。

## JWP002 — iPhoneへの接続

専用ホストとバージョン固定Web起動物、開始画面、ドラッグと長押し状態機械、音の有効／無効、5SEの明示的なデバッグ試聴、Canvasの実表示サイズ、縦持ち案内、Safe Area、非表示時の解除を作る。

バリアの保持状態は輪の仮表示で確認してよい。水の実消費・押し返しはJWP004。泡／電撃ボタンは未実装状態を明示し、試聴ボタンを「ゲームで成功した音」と偽らない。

ゲート：INP群、WEB群のE0で検証可能な範囲、AUD01/06/07。端末がない場合もWeb成果物・操作手順まで作り、実機試験をNOT_RUNにする。これが最初の停止・報告地点。

## JWP003 — バディ・構図・描画順

同じワールドにbuddyを加え、仮スプライトプロップを深度順へ混ぜる。限定yaw20→35°、FOLLOW→OVERVIEW、FOCUSデモとRETURN、pan_demo、デッドゾーン、簡易輪郭を確認する。

フォーカスの試験用UIは簡素でよい。長編調査文や本格メンダコ絵は作らない。ゲート：CAM群、REN群、BDY群。

## JWP004 — 通常個体とバリア

通常ウニの遅い接近、ノックバックとREST、未防御接触、バリアの毎秒消費、供給停止／稼働蛇口、安全地帯、補給UIを接続する。資源モデルとGameEventをここで固定し、`barrier_repelled` と `action_denied` を実判定から鳴らす。

ゲート：ENM01〜03、RES01/02/05/06、COM01〜03、INT02/04/05、AUD02/04。

## JWP005 — 一体だけの連携アクション

異常個体の予兆・有限ダッシュ・硬直、泡の実軌道、壁優先sweep、捕獲、期限解除、手動電撃、行動用電力、日なた充電を実装する。押しっぱなし連続放電や、カメラ外で永久捕獲などの抜け道を先に試験する。

電撃を指示した瞬間にゲーム判定を確定し、0.16秒の視覚演出とは分離する。捕獲時間ぎりぎりの押下でも二重処理しない。

ゲート：ENM04〜06、COM04〜10、RES03/04/07、AUD02〜05。

## JWP006 — 探索一周の成立

本番の短い調査パネルと安全判定、既読集合、FOCUS、補給処理中の世界停止、現在ベース構図への復帰を接続する。必要な外付けの記号・小粒子・草反応だけを加える。

音・粒子・HUDを消してもモデルが同じように動くことを確認する。オノマトペ文字、常時画面揺れ、BGMを追加しない。ゲート：INT群、TIME群、FX群。

## JWP007 — 軽量化を検証する

静的登録、チャンクbounds、visual bounds、可視ソート、active集合、捕獲／弾のpin、安定seed、環境アニメの位相を完成させる。初期データのバッファサイズを大幅に変える前に測定する。

カリングON/OFFのゲーム状態・主要イベント一致を比較する。装飾+128/512を実測し、オブジェクト数だけで速度を推定しない。ゲート：CUL群、PERF群。

## JWP008 — 最終報告

受入表へ結果を記入し、起動手順、操作、既知の制約、次の調整候補をREADMEへまとめる。実行物、Webビルド、設定、必要な権利表示を確認する。端末実機、音の聞き分け、日本語表示など未確認は正直に残す。

最終報告の見出しは「実装内容／検証結果／実機未確認点／変更した仮値と理由／差分・コミット状態／次のウェーブ」。無関係な機能追加を続けず、完成範囲を示して終了する。
