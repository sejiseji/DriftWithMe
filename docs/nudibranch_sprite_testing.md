# 電気ウミウシの素材表示テスト

公開版のURLに `?debug=weeks` を付け、週移動メニューの
「Nudibranch sprite test」を選ぶ。Mac版は `python main.py --week-debug`。
素材テストは月のシナリオと独立しており、7・8月は引き続き準備中。

浅瀬の既存マップ上に通常型と触手4本付き異常型を表示する。
8方向を2秒ごとに切り替え、各方向の4コマを6fpsで3周する。
「Next dir」は自動方向切替を止めて次の方向へ進み、「Auto」は自動切替を戻す。
「Pause」はコマと方向を停止。「WATER/GRASS」は浅瀬と草地を切り替える。
「Week menu」で週選択へ戻り、「Normal play」で通常タイトルへ戻る。

64×64、アンカー[32,58]、透明色8、world_size[20,20]。
通常と同じ高さ基準投影・奥行きソート・大気効果を使う。
透明色8は黒とは異なるため、黒い輪郭も維持する。
異常型のback/body/frontは承認済み素材で合成済み。実時間IKではない。
素材は初回テスト時だけ読み込み、通常の敵リスト・AI・既存ウニは変更しない。
テスト中は世界のシミュレーションを停止し、表示時間だけ進める。

通常セーブ・バックアップは週移動テストの一時ストアで保護する。
終了・週移動・再入場では新しいモデルを作り、プレビュー状態を捨てる。
再読み込みではテスト進行を保存しない。通常復帰時だけ通常保存を読む。

元の静止版version1は保持。7月案件や集中レーザー戦闘の実装には含めない。
