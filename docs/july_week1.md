# 7月第1週：巨木周辺の防除と調査案内

6月第4週の完了後、既存の暗転・週タイトルから7月第1週へ進みます。7月第2週以降は未制作のままです。既存週テスト（`--week-debug` / Web `?debug=weeks`）でも7月第1週のみ選択できます。テストの通常セーブ・バックアップへの書き込みは禁止を維持しています。

勤務開始に上司の夏季休暇申請の一往復を置き、住民課の防除当番へつなぎます。サガンは建設課の発注・確認側、フジは施工側。ジャックが発注を判断する流れはありません。新会話に保護区・採集許可の設定を持ち込んでいません。

防除対象は通常2・異常2の電気ウミウシ、合計4体の固定IDです。6月のウニを入れ替え、撃破済み個体は再出動・ロードで再生成しません。既存の泡捕縛と同じ操作から、通常放電の代わりに集中レーザーへ接続します。電撃ダメージは与えません。異常個体は予告時に凍結したジグザグ経路を高速突進し、途中追尾せず、終了後に短い隙を作ります。承認済み8方向4コマ・異常触手と既存牽制→6ビット泡→時間差の弓形レーザー→加速直進の一点集中→ディゾルブを再利用します。

4体の駆除と最後の戦闘復帰後、一度だけジャック／ヒューズの短い会話、暗転、立ち位置の調整、研究者登場へ進みます。承認済みの2人の32×32マップ素材を、フジと同じ足アンカー・ワールド寸法・立体ビルボード描画で表示します（july_researcher_map_sprite_contract.md）。静止1方向で、歩行処理は追加していません。両素材の正常ロード時はTEMP表示を消し、欠落・不正な素材には明示的な仮マーカーを残します。会話では採用済みユメサキ・ミヤノの立ち絵を使います。フジは既存のマップ素材を再利用します。NPC本文黄色・ジャック／ヒューズ本文白・立ち絵の復帰と消去・会話枠前面は共通描画です。

研究者には当日の植物共生調査予定を聞き、巨木周辺と整備中区画を案内します。具体時刻は設定していません。『調査が終わる頃まで見回る』『見かけたら近づかず声をかける』という約束のまま、確認済みなら帰庁暗転でその後の巡回時間を省略します。確認が残ればマップ操作へ戻ります。途中の手動帰庁・再出動も同じ記録を引き継ぎます。

確認会話は、追加資材なし・水源の新規流入なし／安定で短く完結します。フジから、6月の野草の小さな寄せ植え鉢を手伝いへのお礼として受け取り、受領フラグを保存します。確認済みは短い返答とし、受領済みの鉢を差し出す会話は繰り返しません。別のお使い・ED画面・薬剤散布装置の後続事件は追加していません。

保存形式version2は維持し、7月の独立進捗をoffice内へ追加。旧6月v1/v2を読み込み、6月の撃破・報告記録を敵入替中も保全します。駆除済み集合、確認2件、研究者登場／案内済み、会話カーソル、記念品受領を保存し、演出と報告の二重実行を防止します。戦闘中の一時GPU・レーザー状態は保存せず、安全なチェックポイントで再開します。

検証は保存・戦闘・実進行順2種・途中帰庁・連打・ロード・6月回帰の回帰テストと全体check_all、freshブラウザの実操作です。実ブラウザ記録の戦闘→登場確認では、一部の前提状態をテスト用に調整しています。調整範囲は納品した検証記録に明記します。この仕上げ差分のcommit・push・公開は行っていません。
